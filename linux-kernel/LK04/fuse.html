Disadvantages of userfaultfd

As briefly explained in the previous chapter, userfaultfd is standard in current Linux and is not available to general users. To be precise, page faults that occur in user space can be detected, but page faults that occur in kernel space cannot be detected by userfaultfd created by general users. These are security mitigation mechanisms introduced in the following patches.

  • userfaultfd: allow to forbid unprivileged users
  • Control over userfaultfd kernel-fault handling

Therefore, this time we will use a mechanism called FUSE, which is one of the functions of Linux. First, let's learn what FUSE is.

What is FUSE?
